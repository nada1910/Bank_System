# Bank_System
A C-based Bank Management System developed as a university project for Programming (1) at the Faculty of Engineering, Alexandria University.
The system is designed to create and maintain bank accounts while providing bank employees with functionality for managing customer information, performing financial transactions, searching and sorting accounts, and maintaining transaction history.
Overview
-The system is designed to create and maintain bank accounts and allows bank employees to manage account information and perform financial transactions.
Features
-Login using credentials stored in users.txt
-Load & Save account data using accounts.txt
-Search accounts by account number
-Advanced Search by customer name
-Add new accounts
-Modify account information
-Delete accounts with zero balance
-Change Account Status
-Deposit & Withdraw
-Transfer money between accounts
-Transaction Reports with account history
-Sort & Print accounts by name, balance, or date
Learning Outcomes
-Modular C programming
-File handling
-Data structures
-Searching and sorting algorithms
-Input validation and error handling
-Building a menu-driven application
